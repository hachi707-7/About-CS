Computer Hardware

internal hardware components

  • Internal hardware components are the physical parts hidden inside a computer case that work together to run programs and process data
  • Motherboard: The main circuit board that connects all parts together so they can talk to each other.
  • Central Processing Unit: The "brain" of the computer that does the math and runs programs.
  • Random Access Memory: The short-term memory that holds data your computer needs right now while turned on.
  • Storage:The long-term memory that saves your files and apps even when the computer is turned off.
  • Power Supply Unit: The part that changes electricity from the wall outlet into power safe for the computer parts.

    External Hardware components

  • External hardware components are physical parts that plug into the outside of a computer to help you use it
  • synonme for hardware componets is peripherals which means any hardware piece that sits outside the main computer case is often called a peripheral device.
  • The keyboard lets you type: A Keyboard is an input device used to enter letters, numbers, and commands.
  • The mouse helps you click: A Mouse is an input tool that moves the pointer or cursor around your screen.
  • The monitor shows the picture: A Monitor is an output device that displays visual data, images, and video.

    Hardware maintenance and cleaning

  • Hardware maintenance and cleaning is the physical care of a computer's parts to keep it running smoothly and prevent permanent damage
  • Dust is the enemy: Over time, dust blocks the vents and coats internal fans.
  • Power down first: You must always completely turn off and unplug a computer before cleaning it.
  • No harsh liquids: Liquid should never be sprayed directly onto computer hardware.
  • Say no to vacuums: Standard household vacuum cleaners generate massive amounts of static electricity
