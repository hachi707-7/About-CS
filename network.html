TCP 3-Way Handshake Breakdown

Step 1: SYN (Synchronize)

Client sends a packet with SYN flag set and initial sequence number (e.g. Seq=100) to request a new TCP session.

Step 2: SYN-ACK (Synchronize-Acknowledge)

Server responds with SYN-ACK flags set, acknowledging client's SYN (Ack=101) and sending its initial sequence number (Seq=300).

Step 3: ACK (Acknowledge)

Client confirms server's response (Ack=301). Connection is established (ESTABLISHED state), allowing HTTP payload data exchange.
